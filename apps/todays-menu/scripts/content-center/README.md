# HANKKI Content Center (CONTENT-CENTER-1)

Internal developer tool. **Not** part of the mobile app.

## Launch

```bash
cd apps/todays-menu
npm run content-center
```

Open: http://127.0.0.1:4720

## Scope (MVP)

- Hero image review (Approve / Regenerate / Reject)
- Ingredient icon status (exists / missing / fallback) — display only
- Recipe readiness (Ready / Review needed / Missing assets)

Cooking-step image management is out of scope.
