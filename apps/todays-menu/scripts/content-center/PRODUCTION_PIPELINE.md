# CONTENT-3 — Production Pipeline

Internal workflow only. Does not modify the consumer app UI.

## Commands

```bash
# Progress dashboard
npm run produce:progress

# Generate next 20 missing heroes → Review only
npm run produce:heroes:generate

# Preview / batch-approve heroes (requires --confirm after human review)
npm run produce:heroes:approve
npm run produce:heroes:approve -- --confirm --limit=20
npm run produce:heroes:approve -- --confirm --from=031 --to=050

# Generate next 20 missing ingredient icons → Review only
npm run produce:ingredients:generate

# Preview / batch-approve ingredient icons (requires --confirm)
npm run produce:ingredients:approve
npm run produce:ingredients:approve -- --confirm --limit=20

# Content Center UI progress
npm run content-center
```

## Safety

- Generate never auto-approves
- Approve requires explicit `--confirm`
- Approved assets are never regenerated by generate commands
