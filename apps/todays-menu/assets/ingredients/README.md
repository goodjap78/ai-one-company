# Ingredient icons (Sprint R3)

Place PNG icons here and register them in
`services/images/ingredientImageAssets.ts` with a static `require()`.

Expected keys / files:

- pork.png
- kimchi.png
- tofu.png
- green_onion.png
- onion.png
- zucchini.png
- mushroom.png
- green_chili.png
- mushroom.png
- gochugaru.png
- soy_sauce.png
- garlic.png
- doenjang.png
- sesame_oil.png

Do not use dynamic `require()`. Missing files must not be registered.
