# 된장찌개

**ID:** `gold_kr_doenjang_jjigae`  
**Type:** MAIN · **Meal Style:** recipe · **Cuisine:** Korean · **Mode:** 집에서  
**Cook Time:** 30분 · **Difficulty:** 쉬움 · **Servings:** 2

## Short Description

된장과 채소로 끓이는 순한 국물 한 그릇, 온 가족이 편하게 먹기 좋은 기본 집밥이에요.

## Required Ingredients

| 재료 | 양 |
|------|-----|
| 된장 | 2큰술 |
| 두부 | 1/2모 |
| 애호박 | 1/4개 |
| 감자 | 1/2개 |
| 대파 | 1대 |
| 청양고추 *(있으면 더 좋아요)* | 1/2개 |

---

## Cooking Support

**Tip:** 된장은 체에 풀어 넣으면 국물이 맑아요.

| Step | Guide | Instruction |
|------|-------|-------------|
| 1 | 이제 하나씩 만들어볼게요. | 감자와 애호박은 먹기 좋은 크기로 썰어요. |
| 2 | 채소가 익을 시간을 주세요. | 물 2컵을 끓이고 감자를 먼저 넣어요. |
| 3 | 된장 풀 때 불을 줄이면 덜 끓어요. | 된장을 풀어 넣고 두부와 애호박을 넣어요. |
| 4 | 마지막에 넣으면 향이 살아요. | 대파를 넣고 2분 더 끓여요. |
