# Prompt Rules

## Location

- Per-recipe hero prompts: `generated/image-factory/prompts/{heroImageKey}.md`  
- Company prompt libraries: `AI_Company_OS/10_Assets/Prompt_Libraries/`  
- Image prompt catalogs: `AI_Company_OS/10_Assets/Image_Prompts/`

## Style (food heroes)

Always include constraints:

- ultra realistic / warm lighting / restaurant quality  
- no text, logo, watermark, people, hands  
- horizontal / mobile-app friendly  

## Rules

1. Prompts are reviewed before paid generation  
2. Keep Korean dish name + English key in every prompt  
3. Do not store API keys inside prompt files
