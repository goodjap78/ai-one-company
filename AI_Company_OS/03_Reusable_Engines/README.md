# 03 — Reusable Engines

## Purpose

Document every **reusable engine** so future projects adapt systems instead of reinventing them.

## When to use

- A subsystem is extracted or designed for multi-project reuse
- An existing HANKKI / company tool should be reused elsewhere
- Onboarding engineers need an architecture overview

## How to use

1. Copy [`../09_Templates/Engine_Template.md`](../09_Templates/Engine_Template.md)
2. Create `Engine_Name.md` in this folder
3. Document: Purpose, Architecture, Flow, Reusable projects, Version History
4. Keep code paths as links — this folder is knowledge, not source
