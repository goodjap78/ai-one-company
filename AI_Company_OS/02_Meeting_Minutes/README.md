# 02 — Meeting Minutes

## Purpose

Store every meeting so decisions, problems, ideas, and owners are recoverable.

## When to use

- Sprint planning / review
- Architecture reviews
- Cross-project syncs
- Vendor / partnership calls that affect product

## How to use

1. Copy [`../09_Templates/Meeting_Template.md`](../09_Templates/Meeting_Template.md)
2. Save as `YYYY-MM-DD-topic-kebab.md`
3. Fill: Summary, Decisions, Problems, Ideas, Action Items, Owner, Priority
4. Link any new Decisions created during the meeting
