# 09 — Templates

## Purpose

Reusable document templates. Always start from a template — never invent a new structure mid-doc.

## When to use

Before writing any Decision, Meeting, Sprint, Feature, Bug, Engine, Lesson, or Idea doc.

## How to use

1. Copy the template file
2. Rename with the folder’s naming convention
3. Delete unused optional sections only after filling required ones
