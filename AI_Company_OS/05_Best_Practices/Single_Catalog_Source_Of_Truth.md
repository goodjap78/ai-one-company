# Best Practice — Single Catalog Source of Truth

## Workflow

1. Pick one Home catalog (`HANKKI_RECIPES`)  
2. Mark others legacy with adapters  
3. New content only enters the primary catalog  
4. Cut over search/detail when ready — then archive  

## Why it works

- Stops ID / image / ranking splits  
- Cleanup becomes safe
