# 05 — Best Practices

## Purpose

Collect **successful workflows** that should be repeated deliberately.

## When to use

- After a sprint that went well — capture the workflow
- Before a similar sprint starts — reuse the checklist

## How to use

1. Write one short doc per practice (problem → workflow → outcome)
2. Link related engines / standards
3. Prefer concrete steps over slogans
