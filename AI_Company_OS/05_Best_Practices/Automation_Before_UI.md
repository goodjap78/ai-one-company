# Best Practice — Automation Before UI

## Workflow

1. Define data / asset contracts  
2. Build factory or engine (CLI)  
3. Generate manifests / prompts / queues  
4. Only then change UI if the sprint requires it  

## Why it works

- Protects North Star UX from drive-by redesign  
- Makes progress measurable without pixel churn  

## Example

IMG-1 / IMG-2 delivered full image production without touching Home or Recipe Detail.
