# 07 — Future Ideas

## Purpose

Store ideas that must **not** interrupt current development.

## When to use

- Brainstorm during a sprint
- Feature request that fails the north-star test today
- Multi-project opportunities (ShoppingBag, Adsense, AI Goods)

## How to use

1. Copy [`../09_Templates/Idea_Template.md`](../09_Templates/Idea_Template.md)
2. Save as `IDEA-XXXX-short-title.md`
3. Fill: Description, Business value, Priority, Target version
4. Do **not** start implementation from this folder alone — promote via Roadmap + Decision
