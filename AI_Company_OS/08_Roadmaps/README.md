# 08 — Roadmaps

## Purpose

One living roadmap **per project** — status, near-term work, parked items.

## When to use

- Sprint planning
- Status for investors / partners / yourself in 90 days
- Deciding what *not* to build

## How to use

1. Keep roadmap documents short; link deep specs in `docs/` or engine folders
2. Update Status table every sprint
3. Move completed work to a short “Shipped” section — do not delete history blindly
