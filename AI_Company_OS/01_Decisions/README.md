# 01 — Decisions

## Purpose

Store every important **company decision** so we never re-debate settled choices without context.

## When to use

- Architecture choice (catalog source of truth, provider strategy, monorepo layout)
- Product principle changes
- Cross-project tooling standards
- Go / no-go for major investments

## How to use

1. Copy [`../09_Templates/Decision_Template.md`](../09_Templates/Decision_Template.md)
2. Save as `DEC-XXXX-short-kebab-title.md` in this folder
3. Fill: Date, Project, Decision, Why, Expected impact, Related files, Status
4. Add a row to [`../Knowledge_Index.md`](../Knowledge_Index.md)

## Status values

`Proposed` · `Accepted` · `Superseded` · `Rejected`

## Naming

`DEC-0001-knowledge-os-established.md`
