# Prompt Libraries

## Purpose

Reusable prompt packs (not one-off generated files).

## When to use

Starting a new generation domain (food, product, character, ads).

## How to use

1. Add a `.md` pack per domain  
2. Link from Project Standards → Prompt Rules  
3. Version the pack when constraints change
