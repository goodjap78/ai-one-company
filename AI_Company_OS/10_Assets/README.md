# 10 — Assets

## Purpose

Company creative & brand knowledge: guidelines, characters, prompt libraries, design systems, image prompts.

Binary assets may live in app trees (`apps/*/assets`) or shared packages; **descriptions and rules** live here.

## When to use

- Onboarding designers / marketers
- Reusing Seed / brand characters across apps
- Sharing image-generation prompt libraries

## How to use

1. Document the asset *system* here (rules, versions, usage)
2. Link to actual files in the repo
3. Never commit secrets or licensed stock without attribution notes
