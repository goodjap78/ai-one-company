## How to use

1. Copy [`../09_Templates/Lesson_Template.md`](../09_Templates/Lesson_Template.md)
2. Save as `LESSON-XXXX-short-title.md`
3. Fill: Problem, Cause, Solution, Future prevention
4. Link related Decisions
